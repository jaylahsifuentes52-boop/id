OXLAN AI HUB — COLORFUL UPGRADE

Included:
- index.html — home page and Get help page
- style.css — colorful purple/blue/green/orange design, responsive layout
- app.js — chat UI, recent chats, theme toggle, settings, help topics and help form

PREVIEW:
1. Extract the ZIP.
2. Open index.html in a browser.

GET HELP:
- Click Get help in the sidebar or top bar.
- Choose a help topic, or fill in the form and press Prepare help message.
- The form prepares text for you to copy; it does not send to a real support team.

IMPORTANT:
The chat uses example replies and is not connected to a real AI model. For real AI, add a secure server/backend that calls an AI provider. Do not place private API keys in public JavaScript.

PUBLISH:
Upload the extracted website files to your preferred static host. Keep index.html, style.css, and app.js in the same folder.
